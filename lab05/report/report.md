# Контрольные вопросы

1. **Какая команда используется для просмотра списка VLAN на сетевом устройстве?**

   Для просмотра списка VLAN на коммутаторе Cisco используется команда:

   `show vlan brief`

   Данная команда выводит таблицу, содержащую номера VLAN, их имена, состояние и список портов, принадлежащих каждой VLAN. Это позволяет администратору быстро определить, какие виртуальные сети настроены на устройстве и какие интерфейсы входят в их состав.

   Также могут использоваться дополнительные команды:

   - `show vlan` — отображает подробную информацию о VLAN;
   - `show interfaces trunk` — показывает список trunk-портов и VLAN, передаваемых по ним;
   - `show running-config` — отображает текущую конфигурацию устройства, включая настройки VLAN.

2. **Охарактеризуйте VLAN Trunking Protocol (VTP). Приведите перечень команд с пояснениями для настройки и просмотра информации о VLAN.**

   **VLAN Trunking Protocol (VTP)** — это протокол канального уровня, разработанный компанией Cisco, предназначенный для централизованного управления VLAN в сети коммутаторов.  
   Он позволяет автоматически распространять информацию о VLAN между коммутаторами, что упрощает администрирование сети и предотвращает ошибки конфигурации.

   В сети VTP могут использоваться три режима работы устройств:

   - **Server** — коммутатор может создавать, изменять и удалять VLAN, а также распространяет информацию о них другим устройствам;
   - **Client** — коммутатор получает информацию о VLAN от сервера, но не может изменять базу VLAN;
   - **Transparent** — коммутатор не участвует в синхронизации VLAN, но может передавать VTP-сообщения дальше.

   Основные команды настройки VTP:

   - `vtp mode server` — переводит коммутатор в режим VTP-сервера;
   - `vtp mode client` — переводит коммутатор в режим VTP-клиента;
   - `vtp domain <имя>` — задаёт имя домена VTP;
   - `vtp password <пароль>` — устанавливает пароль для синхронизации VTP;
   - `vlan <номер>` — создаёт новую VLAN;
   - `name <имя>` — задаёт имя VLAN.

   Команды для просмотра информации:

   - `show vtp status` — отображает состояние VTP и параметры домена;
   - `show vlan brief` — показывает список VLAN и назначенные порты;
   - `show interfaces trunk` — отображает trunk-интерфейсы и передаваемые VLAN.

3. **Охарактеризуйте Internet Control Message Protocol (ICMP). Опишите формат пакета ICMP.**

   **ICMP (Internet Control Message Protocol)** — это протокол сетевого уровня, предназначенный для передачи служебных сообщений и диагностики сети.  
   Он используется для уведомления об ошибках доставки пакетов и проверки доступности сетевых устройств.

   Наиболее известное применение ICMP — команда `ping`, которая отправляет сообщение **Echo Request** и ожидает ответ **Echo Reply**.

   Формат пакета ICMP включает следующие поля:

   - **Type** — тип сообщения (например, 8 — Echo Request, 0 — Echo Reply);
   - **Code** — уточнение типа сообщения;
   - **Checksum** — контрольная сумма для проверки целостности пакета;
   - **Identifier** — идентификатор запроса;
   - **Sequence Number** — порядковый номер пакета;
   - **Data** — полезные данные.

   ICMP-пакет инкапсулируется в IP-пакет и передаётся по сети вместе с другими протоколами.

4. **Охарактеризуйте Address Resolution Protocol (ARP). Опишите формат пакета ARP.**

   **ARP (Address Resolution Protocol)** — это протокол канального уровня, предназначенный для определения MAC-адреса устройства по его IP-адресу в локальной сети.

   Когда устройство хочет отправить пакет другому узлу в той же сети, оно должно знать MAC-адрес получателя. Если этот адрес неизвестен, устройство отправляет широковещательный ARP-запрос, содержащий IP-адрес искомого узла. Устройство с соответствующим IP-адресом отвечает ARP-ответом, содержащим свой MAC-адрес.

   Основные поля ARP-пакета:

   - **Hardware Type** — тип аппаратного интерфейса (например, Ethernet);
   - **Protocol Type** — тип сетевого протокола (обычно IPv4);
   - **Hardware Size** — размер MAC-адреса;
   - **Protocol Size** — размер IP-адреса;
   - **Opcode** — тип операции (ARP Request или ARP Reply);
   - **Sender MAC Address** — MAC-адрес отправителя;
   - **Sender IP Address** — IP-адрес отправителя;
   - **Target MAC Address** — MAC-адрес получателя;
   - **Target IP Address** — IP-адрес получателя.

   ARP работает только внутри локальной сети и является важным механизмом взаимодействия между сетевым и канальным уровнями модели OSI.

5. **Что такое MAC-адрес? Какова его структура?**

   **MAC-адрес (Media Access Control Address)** — это уникальный физический адрес сетевого интерфейса, используемый на канальном уровне модели OSI для идентификации устройств в локальной сети.

   MAC-адрес состоит из **48 бит (6 байт)** и обычно записывается в шестнадцатеричном формате, например:

   `00:1A:2B:3C:4D:5E`

   Структура MAC-адреса состоит из двух частей:

   - **OUI (Organizationally Unique Identifier)** — первые 24 бита, идентификатор производителя сетевого оборудования;
   - **NIC Specific** — последние 24 бита, уникальный номер устройства, присваиваемый производителем.

   MAC-адрес используется коммутаторами для построения таблицы MAC-адресов и правильной передачи Ethernet-кадров внутри локальной сети.

Один из коммутаторов был настроен в режиме VTP-сервера, на котором были созданы VLAN и заданы их имена. Остальные коммутаторы сети были настроены в режиме VTP-клиентов, благодаря чему информация о VLAN автоматически распространялась по сети. Также были настроены trunk-порты, обеспечивающие передачу трафика нескольких VLAN между коммутаторами.

На оконечных устройствах были назначены статические IP-адреса и указаны соответствующие шлюзы по умолчанию. После настройки сети выполнена проверка связности устройств с помощью команды ping. В результате установлено, что устройства успешно обмениваются данными внутри одной VLAN, в то время как обмен данными между разными VLAN отсутствует из-за отсутствия маршрутизации между ними.

С использованием режима Simulation в Cisco Packet Tracer был изучен процесс передачи ICMP-пакетов по сети, а также рассмотрена структура передаваемых кадров Ethernet и заголовков протоколов IP и ICMP.

Выполненная работа позволила изучить принципы сегментации сети с помощью VLAN, работу протокола VTP, а также особенности передачи сетевых пакетов и взаимодействия устройств внутри виртуальных локальных сетей.
