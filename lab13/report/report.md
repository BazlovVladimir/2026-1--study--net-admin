# Контрольные вопросы

1. **В каких случаях следует использовать статическую маршрутизацию? Приведите примеры.**

   **Статическая маршрутизация** — это способ маршрутизации, при котором маршруты до удалённых сетей вручную задаются администратором на маршрутизаторах. В отличие от динамической маршрутизации, статические маршруты не изменяются автоматически при изменении топологии сети.

   Статическую маршрутизацию следует использовать в тех случаях, когда структура сети достаточно простая, стабильная и редко изменяется. Такой подход удобен для небольших сетей, где количество маршрутизаторов и подсетей ограничено, а администратор может вручную контролировать все маршруты.

   Статическая маршрутизация применяется в следующих случаях:

   - в небольших локальных сетях с несколькими маршрутизаторами;
   - при подключении удалённого филиала к центральной сети;
   - для настройки маршрута по умолчанию в сторону провайдера или центрального маршрутизатора;
   - для организации резервного маршрута с увеличенной административной дистанцией;
   - в учебных и лабораторных сетях, где важно вручную отработать принципы маршрутизации;
   - в сетях, где требуется полный контроль над путём прохождения трафика.

   Например, если сеть филиала в г. Сочи подключена к основной сети организации через один маршрутизатор, то на маршрутизаторе филиала можно задать статический маршрут в сторону центральной площадки. В этом случае весь трафик к внутренним сетям организации будет отправляться через указанный next-hop-адрес.

   Пример статического маршрута:

   `ip route 10.128.0.0 255.255.0.0 10.128.255.5`

   В данном случае маршрутизатор будет отправлять трафик к сети `10.128.0.0/16` через следующий узел `10.128.255.5`.

   Другой распространённый пример — настройка маршрута по умолчанию для выхода во внешнюю сеть:

   `ip route 0.0.0.0 0.0.0.0 198.51.100.1`

   Основными преимуществами статической маршрутизации являются простота настройки, предсказуемость работы и отсутствие служебного трафика, который создают динамические протоколы маршрутизации. Однако у неё есть и недостатки: при изменении топологии сети маршруты необходимо изменять вручную, поэтому в крупных и часто изменяемых сетях статическая маршрутизация становится неудобной.

2. **Укажите основные принципы статической маршрутизации между VLANs.**

   VLAN используется для логического разделения сети на отдельные широковещательные домены. Устройства, находящиеся в разных VLAN, не могут обмениваться данными напрямую на канальном уровне, даже если они подключены к одному коммутатору. Для передачи трафика между VLAN требуется маршрутизация на сетевом уровне.

   Статическая маршрутизация между VLANs строится на том, что для каждой VLAN создаётся отдельная IP-подсеть, а маршрутизатор или L3-коммутатор выполняет передачу пакетов между этими подсетями.

   Основные принципы статической маршрутизации между VLANs:

   - каждая VLAN должна иметь собственную IP-подсеть;
   - для каждой VLAN должен быть настроен шлюз по умолчанию;
   - шлюзом для устройств VLAN обычно выступает интерфейс маршрутизатора или SVI-интерфейс L3-коммутатора;
   - если используется схема Router-on-a-Stick, то на маршрутизаторе создаются подынтерфейсы для каждой VLAN;
   - между коммутатором и маршрутизатором настраивается trunk-соединение;
   - на подынтерфейсах маршрутизатора указывается номер VLAN через инкапсуляцию `dot1Q`;
   - на маршрутизаторах вручную задаются статические маршруты до удалённых VLAN-сетей;
   - на конечных устройствах должен быть указан корректный IP-адрес шлюза своей VLAN.

   Например, если в сети используются VLAN 201 и VLAN 301, то для них могут быть выделены разные подсети:

   - VLAN 201 — `10.129.0.0/24`;
   - VLAN 301 — `10.129.1.0/24`.

   Для маршрутизации между ними на маршрутизаторе могут быть созданы подынтерфейсы:

   `interface FastEthernet0/0.201`  
   `encapsulation dot1Q 201`  
   `ip address 10.129.0.1 255.255.255.0`

   `interface FastEthernet0/0.301`  
   `encapsulation dot1Q 301`  
   `ip address 10.129.1.1 255.255.255.0`

   В этом случае адрес `10.129.0.1` будет шлюзом для устройств VLAN 201, а адрес `10.129.1.1` — шлюзом для устройств VLAN 301.

   Если VLAN находятся за разными маршрутизаторами, то на каждом маршрутизаторе дополнительно необходимо прописать статические маршруты до удалённых сетей. Например, маршрутизатор основной территории должен знать маршрут до сети филиала, а маршрутизатор филиала — маршрут до сетей основной территории.

   Пример маршрута с основной территории в сторону филиала:

   `ip route 10.130.0.0 255.255.255.0 10.128.255.6`

   Пример обратного маршрута из филиала в сторону основной территории:

   `ip route 10.129.0.0 255.255.255.0 10.128.255.5`
