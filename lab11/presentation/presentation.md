# VLAN и подсети

## Таблица VLAN

| VLAN | Имя         | Назначение |
|-----:|-------------|------------|
| 2    | management  | Управление устройствами |
| 3    | servers     | Серверная ферма |
| 4    | provider    | Связь с провайдером |
| 101  | dk          | Дисплейные классы |
| 102  | departments | Кафедры |
| 103  | adm         | Администрация |
| 104  | other       | Другие пользователи |

## Основные IP-подсети

| Подсеть          | Назначение |
|------------------|------------|
| 10.128.0.0/24    | Серверная ферма |
| 10.128.1.0/24    | Управление |
| 10.128.3.0/24    | Дисплейные классы |
| 10.128.4.0/24    | Кафедры |
| 10.128.5.0/24    | Администрация |
| 10.128.6.0/24    | Другие пользователи |
| 198.51.100.0/24  | Сеть провайдера |
| 192.0.2.0/24     | Модельный Интернет |

# Итоги работы

## Вывод

В ходе лабораторной работы:

- модернизирована схема сети с добавлением провайдера и модельного Интернета;
- выполнено размещение и подключение нового оборудования;
- настроены имена устройств и IP-адресация;
- подготовлены VLAN, подсети и портовая схема;
- изучены назначение NAT, его признаки и основные типы.

Получены практические навыки подготовки локальной сети  
к подключению к внешней сети и дальнейшей настройке NAT.
