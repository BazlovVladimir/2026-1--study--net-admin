# Контрольные вопросы

1. **В чём состоит основной принцип работы NAT (что даёт наличие NAT в сети организации)?**  

   **NAT (Network Address Translation)** — это технология преобразования IP-адресов, при которой внутренние (частные) адреса локальной сети заменяются на внешние (публичные) при выходе в Интернет.  

   Основной принцип заключается в том, что маршрутизатор изменяет IP-адрес источника (а иногда и порт) в исходящем пакете и ведёт таблицу соответствия между внутренними и внешними адресами. При получении ответного пакета выполняется обратное преобразование.  

   Использование NAT позволяет:
   - экономить публичные IP-адреса;
   - скрывать внутреннюю структуру сети (повышение безопасности);
   - обеспечивать доступ локальной сети в Интернет через один или несколько внешних адресов.

2. **В чём состоит принцип настройки NAT (на каком оборудовании и что нужно настроить для выхода из локальной сети во внешнюю сеть через NAT)?**  

   NAT настраивается на маршрутизаторе, который соединяет локальную (внутреннюю) сеть с внешней сетью (Интернетом).  

   Для настройки необходимо:
   - определить внутренние (**inside**) и внешние (**outside**) интерфейсы;
   - создать список доступа (ACL), определяющий, какой трафик подлежит преобразованию;
   - при необходимости задать пул внешних IP-адресов;
   - настроить правило NAT (например, динамический NAT или NAT с перегрузкой).  

   В результате маршрутизатор выполняет преобразование адресов для пакетов, выходящих из локальной сети во внешнюю.

3. **Можно ли применить Cisco IOS NAT к субинтерфейсам?**  

   Да, в Cisco IOS NAT может применяться к субинтерфейсам.  
   Субинтерфейсы (например, FastEthernet0/0.1, FastEthernet0/0.4) используются при работе с VLAN (инкапсуляция dot1q), и на них можно назначать команды `ip nat inside` или `ip nat outside`.  

   Это позволяет выполнять трансляцию адресов для разных VLAN, используя один физический интерфейс.

4. **Что такое пулы IP NAT?**  

   **Пул NAT** — это диапазон публичных IP-адресов, который используется для динамического преобразования внутренних адресов.  

   При обращении во внешнюю сеть внутреннему узлу временно назначается один из адресов из пула.  
   Если используется режим **overload (PAT)**, то несколько внутренних адресов могут использовать один внешний IP за счёт различия портов.

5. **Что такое статические преобразования NAT?**  

   **Статический NAT** — это фиксированное соответствие между внутренним и внешним IP-адресом (или адресом и портом).  

   Такое преобразование настраивается вручную и не изменяется со временем.  
   Оно используется для публикации внутренних серверов во внешней сети, например:
   - WEB-сервер (порт 80);
   - FTP-сервер (порт 21);
   - почтовый сервер (порты 25 и 110).  

   В этом случае внешний пользователь обращается к публичному адресу, а маршрутизатор перенаправляет запрос на соответствующий внутренний сервер.
