# Цель работы

## Основная цель

Разработать план локальной сети организации:

- спроектировать уровни L1, L2, L3;
- выполнить логическое разделение сети на VLAN;
- разработать план IP-адресации;
- подготовить таблицы VLAN, IP и портов.

- 10.128.0.0/24 — серверная ферма  
- 10.128.1.0/24 — управление  
- 10.128.3.0/24 — ДК  
- 10.128.4.0/24 — кафедры  
- 10.128.5.0/24 — администрация  
- 10.128.6.0/24 — другие пользователи  

## Принцип распределения

- .1 — шлюз  
- 2–19 — оборудование  
- 20–29 — серверы  
- 30–199 — DHCP
