# Контрольные вопросы

1. **Как задать действие правила для конкретного протокола?**  

   Действие правила для конкретного протокола задаётся при создании записи в списке управления доступом с указанием имени протокола.  
   В расширенных ACL можно явно указать протокол, например:  
   - `tcp` — для протокола TCP;  
   - `udp` — для протокола UDP;  
   - `icmp` — для ICMP-запросов;  
   - `ip` — для всех протоколов.  

   Пример:  
   `permit tcp any host 10.128.0.2 eq 80` — разрешает доступ по протоколу TCP к серверу по порту 80.  

2. **Как задать действие правила сразу для нескольких портов?**  

   Для задания действия сразу для нескольких портов используются специальные ключевые слова:  
   - `range` — задаёт диапазон портов;  
   - `eq` — для одного конкретного порта;  
   - `gt` / `lt` — для портов больше или меньше заданного значения.  

   Пример:  
   `permit tcp any host 10.128.0.2 range 20 21` — разрешает доступ по диапазону портов (FTP).  

3. **Как узнать номер правила в списке прав доступа?**  

   Номер правила можно узнать с помощью команды:  
   `show access-lists`  

   В выводе команды перед каждым правилом указывается его порядковый номер (sequence number), например:  
   `10 permit tcp any host 10.128.0.2 eq 80`  

   Эти номера используются для идентификации правил и позволяют управлять их порядком в списке.

4. **Каким образом можно изменить порядок применения правил в списке контроля доступа?**  

   Порядок применения правил можно изменить с помощью указания номера (sequence number) при добавлении или редактировании записи ACL.  
   Правила выполняются сверху вниз, поэтому их порядок имеет важное значение.  

   Возможные способы изменения порядка:  
   - добавление нового правила с нужным номером (например, `10`, `20`, `30`);  
   - удаление и повторное добавление правил в нужной последовательности;  
   - вставка правила между существующими, указав промежуточный номер.  

   Пример:  
   `10 permit icmp any any` — правило с меньшим номером будет выполняться раньше остальных.
